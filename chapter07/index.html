    데이터를 그림으로! — 첫 번째 차트 만들기¶

    🎯 이 장에서 배우는 것¶

    • 구글 시트에서 막대 차트를 만들 수 있다
    • 차트 제목, 색상 등 기본 설정을 조정할 수 있다
    • 시각화가 숫자 나열보다 효과적인 이유를 설명할 수 있다

    📚 핵심 개념¶

    개념: 데이터 시각화¶

    1. 비유로 시작: "시각화는 마치 지도와 같아요." 낯선 도시에서 주소 목록만 보면 막막하지만, 지도 위에 표시하면 한눈에 어디가 어딘지 보이잖아요? 숫자 데이터도 똑같습니다. 숫자를 그림(차트)으로 바꾸면 패턴이 한눈에 보여요! 👀

    2. 정확한 정의: 데이터 시각화란 숫자나 텍스트 형태의 데이터를 차트, 그래프 같은 그림으로 변환하여 정보를 직관적으로 전달하는 방법입니다.

    3. 예시로 확인: 5명의 수학 점수가 있다고 해볼게요.

    4. 민수 85, 지영 92, 태호 78, 수빈 95, 하늘 88

    숫자만 보면 "누가 제일 잘했지?" 하고 하나하나 비교해야 하죠. 하지만 막대 차트로 그리면? 막대 높이만 보고 바로 수빈이 가장 높다는 걸 알 수 있어요!

    graph LR A[숫자 데이터] -->|차트로 변환| B[패턴이 보인다!] B --> C[빠른 판단 가능] B --> D[비교가 쉬워짐]

    🔨 따라하기¶

    Step 1: 데이터 입력하고 차트 만들기¶

    구글 시트(sheets.google.com)를 열고 새 스프레드시트를 만드세요.

    입력할 데이터:

    • A1: 과목 / B1: 평균점수
    • A2: 국어 / B2: 82
    • A3: 수학 / B3: 75
    • A4: 영어 / B4: 88
    • A5: 과학 / B5: 79
    • A6: 사회 / B6: 91

    차트 만들기:

    1. A1:B6 영역을 드래그하여 선택 🖱️
    2. 상단 메뉴에서 삽입 → 차트 클릭
    3. 짠! 🎉 자동으로 차트가 나타납니다

    💡 구글 시트가 데이터를 분석해서 알맞은 차트를 자동 추천해줘요. 보통 막대 차트가 먼저 나옵니다!

    Step 2: 차트 꾸미기¶

    차트를 더블 클릭하면 오른쪽에 차트 편집기가 열립니다.

    • 차트 유형: "맞춤설정" 탭 → 원하는 차트 종류 확인 (막대 차트 유지!)
    • 차트 제목: 맞춤설정 탭 → "차트 및 축 제목" → "우리 반 과목별 평균 점수" 입력
    • 색상 변경: 맞춤설정 탭 → "계열" → 원하는 색상 선택 🎨

    완성된 차트를 보세요. 사회가 가장 높고, 수학이 가장 낮다는 것이 1초 만에 파악되지 않나요?

    ⚠️ 주의할 점¶

    • 데이터 영역을 정확히 선택하세요! 빈 셀이 포함되면 차트가 이상하게 나올 수 있어요. 헤더(제목 행)부터 마지막 데이터까지 딱 맞게 드래그하세요.
    • 차트가 안 나오면 데이터에 숫자가 아닌 텍스트가 섞여 있는지 확인해보세요. B열에는 반드시 숫자만 입력해야 합니다.

    ✅ 점검하기¶

    1. 시각화가 숫자 나열보다 효과적인 이유는?

    정답 확인차트로 표현하면 데이터의 크고 작음, 패턴, 경향을 한눈에 직관적으로 파악할 수 있기 때문입니다. 숫자를 하나하나 비교할 필요 없이 막대의 높이만 보면 됩니다.

    2. 구글 시트에서 차트를 만드는 순서 3단계는?

    정답 확인① 데이터 영역 선택 → ② 삽입 메뉴에서 차트 클릭 → ③ 차트 편집기에서 설정 조정

    3. 차트 제목이나 색상을 바꾸려면 어디를 클릭해야 할까요?

    정답 확인차트를 더블 클릭하면 나타나는 "차트 편집기"의 "맞춤설정" 탭에서 제목, 색상, 축 레이블 등을 수정할 수 있습니다.

    🔗 다음 장 미리보기¶

    이번에는 막대 차트 하나를 만들어봤어요. 다음 시간에는 같은 데이터를 다른 차트(원형, 꺾은선 등)로 표현하면 어떻게 느낌이 달라지는지 비교해봅니다. 데이터에 맞는 차트를 고르는 눈을 길러볼 거예요! 📊✨
