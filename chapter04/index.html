    빈칸을 찾아라! — 결측값 이해와 탐색¶

    🎯 이 장에서 배우는 것¶

    • 결측값이 무엇이고 왜 생기는지 설명할 수 있다
    • COUNTBLANK 함수로 빈 셀 개수를 셀 수 있다
    • 조건부 서식으로 빈 셀을 시각적으로 찾을 수 있다

    📚 핵심 개념¶

    개념: 결측값 (Missing Value)¶

    1. 비유로 시작 🎒

    출석부를 생각해보세요. 시험 당일 감기로 결석한 친구가 있다면, 그 친구의 점수 칸은 비어 있겠죠? 이렇게 데이터에서 값이 채워지지 않은 빈칸을 결측값이라고 합니다.

    2. 정확한 정의

    결측값이란 수집되지 않았거나, 기록이 누락된 데이터를 말합니다. 구글 시트에서는 아무것도 입력되지 않은 빈 셀이 바로 결측값입니다.

    3. 왜 문제가 될까?

    5명의 수학 평균을 구한다고 해봅시다. 한 명의 점수가 빠져 있으면 평균이 실제보다 높거나 낮게 나올 수 있어요. 즉, 결측값은 분석 결과를 왜곡합니다! 😱

    💡 결측값이 생기는 대표적 이유 - 결석해서 시험을 못 본 경우 - 데이터 입력 실수로 빠뜨린 경우 - 설문에서 응답을 거부한 경우

    🔨 따라하기¶

    우리의 성적 데이터에는 일부러 빈 셀을 넣어두었어요. 직접 찾아봅시다!

    Step 1: COUNTBLANK로 빈 셀 개수 세기¶

    구글 시트에서 성적 데이터를 열어주세요. 데이터 아래 빈 행에 다음 함수를 입력합니다.

    수학 점수가 B열(B2~B11)에 있다고 가정합니다.

    =COUNTBLANK(B2:B11)

    실행 결과 예시: 

    2

    👉 수학 점수 열에 빈 셀이 2개 있다는 뜻이에요! 영어, 과학 열에도 같은 방식으로 확인해보세요.

    Step 2: 조건부 서식으로 빈 셀 색칠하기¶

    눈으로 하나하나 찾는 건 힘들죠? 빈 셀을 자동으로 노란색으로 칠해봅시다. 🟡

    1. 데이터 전체 범위(예: A1:D11)를 드래그해서 선택
    2. 메뉴에서 서식 → 조건부 서식 클릭
    3. "셀 서식 지정 조건"에서 "비어 있음" 선택
    4. 서식 스타일에서 배경색을 노란색으로 지정
    5. 완료 클릭

    ✨ 빈 셀들이 노란색으로 한눈에 보이나요? 이제 결측값이 어디에 몇 개 있는지 바로 파악됩니다!

    ⚠️ 주의할 점¶

    • 빈 셀 ≠ 0: 점수가 0점인 것과 아예 비어있는 것은 완전히 다릅니다. 0은 "시험을 봤는데 0점", 빈 셀은 "시험 자체를 안 본 것"이에요.
    • 결측값 처리는 신중하게: 빈 칸을 무조건 삭제하거나 0으로 채우면 안 됩니다. 다음 장에서 올바른 처리 방법을 배울 거예요! 🔜

    ✅ 점검하기¶

    1. 결측값이란 무엇인가요?

    정답 확인데이터에서 값이 수집되지 않았거나 누락되어 비어 있는 칸을 결측값이라고 합니다.

    2. COUNTBLANK(C2:C11)의 결과가 3이면 무슨 뜻일까요?

    정답 확인C2부터 C11까지 10개의 셀 중 비어 있는 셀이 3개라는 뜻입니다.

    3. 빈 셀에 0을 넣어도 괜찮을까요?

    정답 확인함부로 0을 넣으면 안 됩니다. 0점과 결측(미응시)은 의미가 다르기 때문에 평균 등 분석 결과가 왜곡될 수 있습니다.
