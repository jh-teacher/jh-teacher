    원하는 데이터만 쏙쏙! — 정렬과 필터 활용¶

    🎯 이 장에서 배우는 것¶

    • 구글 시트에서 데이터를 오름차순/내림차순으로 정렬할 수 있다
    • 필터 기능으로 조건에 맞는 데이터만 골라낼 수 있다
    • 정렬과 필터의 차이를 구분할 수 있다

    📚 핵심 개념¶

    개념: 정렬과 필터¶

    "수학 점수가 가장 높은 학생은 누구일까?" 🤔

    이런 질문에 답하려면 데이터를 눈으로 하나하나 훑어봐야 할까요? 데이터가 10명이면 가능하지만, 100명이면 벌써 막막하죠. 이때 등장하는 두 가지 도구가 바로 정렬과 필터입니다.

    1. 정렬은 마치 줄 세우기와 같아요. 키 순서대로 줄을 세우듯, 점수가 높은 순서(내림차순) 또는 낮은 순서(오름차순)로 데이터 전체의 순서를 바꿉니다.

    2. 필터는 마치 체로 거르기와 같아요. 밀가루에서 덩어리만 걸러내듯, 조건에 맞는 데이터만 화면에 보여주고 나머지는 숨깁니다. 원본 데이터는 그대로예요!

    flowchart LR A["원본 데이터"] -->|정렬| B["순서가 바뀜\n전체 데이터 유지"] A -->|필터| C["조건에 맞는 것만 표시\n나머지는 숨김"]

    💡 핵심 차이: 정렬 = 순서 변경, 필터 = 조건으로 걸러내기

    🔨 따라하기¶

    아래 성적 데이터를 구글 시트 A1셀부터 입력하세요 (또는 복사-붙여넣기!).

    • A열(이름): 이름, 민수, 지은, 하준, 서연, 도윤
    • B열(국어): 국어, 85, 92, 78, 95, 60
    • C열(수학): 수학, 70, 88, 95, 82, 75
    • D열(영어): 영어, 90, 76, 80, 88, 65

    Step 1: 수학 점수 내림차순 정렬 📊¶

    질문: 수학 점수가 가장 높은 학생은?

    1. 데이터가 있는 아무 셀이나 클릭합니다
    2. 메뉴에서 데이터 → 범위 정렬 → 고급 범위 정렬 옵션을 클릭합니다
    3. ✅ "데이터에 머리글 행이 있습니다" 체크
    4. 정렬 기준을 수학 열로 선택합니다
    5. Z → A (내림차순) 를 선택하고 정렬 클릭!

    결과: 하준(95)이 맨 위에! 수학 1등을 바로 찾았어요 🎉

    Step 2: 필터로 국어 80점 이상만 보기 🔍¶

    질문: 국어 점수가 80점 이상인 학생만 보고 싶다면?

    1. 데이터가 있는 아무 셀이나 클릭합니다
    2. 메뉴에서 데이터 → 필터 만들기를 클릭합니다
    3. 머리글 행에 ▼ 아이콘이 생깁니다 — 국어 열의 ▼를 클릭!
    4. 조건별 필터링 → 크거나 같음 → 80 입력 후 확인
    5. 민수(85), 지은(92), 서연(95) — 3명만 화면에 표시됩니다!

    🧹 필터 해제: 데이터 → 필터 삭제를 누르면 전체 데이터가 다시 보여요.

    ⚠️ 주의할 점¶

    • 머리글 포함 주의: 정렬할 때 "머리글 행 있음"을 체크하지 않으면 "이름", "국어" 같은 제목까지 함께 섞여버려요!
    • 필터는 숨기기일 뿐: 필터로 안 보이는 데이터는 삭제된 게 아닙니다. 필터를 해제하면 다시 나타나요 😊

    ✅ 점검하기¶

    1. 정렬과 필터의 가장 큰 차이는 무엇인가요?

    정답 확인정렬은 데이터 전체의 순서를 바꾸는 것이고, 필터는 조건에 맞는 데이터만 보여주고 나머지를 숨기는 것입니다.

    2. 영어 점수가 가장 낮은 학생을 찾으려면 어떻게 정렬해야 할까요?

    정답 확인영어 열 기준으로 오름차순(A→Z) 정렬하면 가장 낮은 점수가 맨 위에 옵니다. (도윤, 65점)

    3. 필터를 적용한 후 안 보이는 데이터는 삭제된 건가요?

    정답 확인아닙니다! 숨겨진 것일 뿐, 필터를 해제하면 모든 데이터가 다시 나타납니다.

    🔗 다음 장 미리보기¶

    지금은 마우스 클릭으로 정렬과 필터를 했는데, 함수로도 데이터를 정렬하고 걸러낼 수 있다는 사실! 다음 장에서는 SORT, FILTER 같은 강력한 함수를 만나봅니다. 클릭 대신 수식 한 줄로 원하는 결과를 뽑아내는 마법을 경험해보세요 ✨
