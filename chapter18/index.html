    막대 차트 심화 — 선수 비교와 항목 비교¶

    Part 3: 데이터를 말하게 하자 — 스포츠 데이터로 시각화 심화

    🎯 이 장에서 배우는 것¶

    • 그룹 막대 차트(묶은 막대)로 여러 항목을 동시에 비교할 수 있다
    • 가로/세로 막대 차트의 적합한 상황을 구분할 수 있다
    • 데이터 정렬로 순위를 시각적으로 표현할 수 있다

    📚 핵심 개념¶

    개념: 그룹 막대 차트 (묶은 막대)¶

    비유로 시작 🏀

    일반 막대 차트가 "이 선수 득점이 몇 점?"이라면, 그룹 막대 차트는 "이 선수 득점도 보고, 어시스트도 나란히 보자!" 입니다. 마치 시험 성적표에서 국어·수학 점수를 나란히 적어놓는 것과 같아요.

    정확한 정의

    하나의 카테고리(선수)마다 두 개 이상의 막대를 나란히 배치하여 여러 항목을 동시에 비교하는 차트입니다. Matplotlib에서는 막대의 x 위치를 직접 조절해서 만듭니다.

    언제 가로 막대를 쓸까? 🤔

    선수 이름처럼 텍스트가 긴 라벨은 세로 차트에서 겹치기 쉽습니다. 이럴 때 가로 막대 차트(barh)를 쓰면 라벨이 깔끔하게 보여요!

    🔨 따라하기¶

    Step 1: 그룹 막대 차트 만들기 (세로)¶

    import matplotlib.pyplot as plt
import numpy as np

# 선수 데이터 (득점 순 정렬)
players = ['손흥민', '김민재', '이강인', '황희찬', '정우영']
goals =   [23, 18, 15, 12, 9]
assists = [7,  3,  11, 5,  8]

x = np.arange(len(players))  # 선수 위치: [0, 1, 2, 3, 4]
width = 0.35  # 막대 너비

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(x - width/2, goals, width, label='득점', color='#FF6B6B')
ax.bar(x + width/2, assists, width, label='어시스트', color='#4ECDC4')

ax.set_xticks(x)
ax.set_xticklabels(players)
ax.set_ylabel('횟수')
ax.set_title('선수별 득점 vs 어시스트')
ax.legend()
plt.tight_layout()
plt.show()

    실행 결과: 선수마다 빨간(득점)·민트(어시스트) 막대가 나란히 표시됩니다. 손흥민이 득점 1위, 이강인이 어시스트에서 강하다는 걸 한눈에 알 수 있어요! 👀

    Step 2: 가로 막대 + 정렬로 순위 차트 만들기¶

    # 득점 순으로 정렬 (내림차순 → 차트에서는 아래가 1위)
sorted_idx = np.argsort(goals)  # 오름차순 인덱스
players_s = [players[i] for i in sorted_idx]
goals_s = [goals[i] for i in sorted_idx]
assists_s = [assists[i] for i in sorted_idx]

y = np.arange(len(players_s))
height = 0.35

fig, ax = plt.subplots(figsize=(8, 5))
ax.barh(y - height/2, goals_s, height, label='득점', color='#FF6B6B')
ax.barh(y + height/2, assists_s, height, label='어시스트', color='#4ECDC4')

ax.set_yticks(y)
ax.set_yticklabels(players_s)  # 이름이 길어도 깔끔!
ax.set_xlabel('횟수')
ax.set_title('🏆 득점 순위 — 선수 비교 차트')
ax.legend()
plt.tight_layout()
plt.show()

    실행 결과: 가로 막대로 바뀌면서 선수 이름이 겹침 없이 읽힙니다. 정렬 덕분에 위→아래로 갈수록 순위가 높아지는 직관적인 차트가 완성돼요! 🎉

    📝 전체 코드¶

    import matplotlib.pyplot as plt
import numpy as np

players = ['손흥민', '김민재', '이강인', '황희찬', '정우영']
goals =   [23, 18, 15, 12, 9]
assists = [7,  3,  11, 5,  8]

# 득점 순 정렬
sorted_idx = np.argsort(goals)
players_s = [players[i] for i in sorted_idx]
goals_s = [goals[i] for i in sorted_idx]
assists_s = [assists[i] for i in sorted_idx]

y = np.arange(len(players_s))
height = 0.35

fig, ax = plt.subplots(figsize=(8, 5))
ax.barh(y - height/2, goals_s, height, label='득점', color='#FF6B6B')
ax.barh(y + height/2, assists_s, height, label='어시스트', color='#4ECDC4')

ax.set_yticks(y)
ax.set_yticklabels(players_s)
ax.set_xlabel('횟수')
ax.set_title('🏆 득점 순위 — 선수 비교 차트')
ax.legend()
plt.tight_layout()
plt.show()

    ⚠️ 주의할 점¶

    • 막대 위치 계산이 핵심! x - width/2와 x + width/2로 나란히 배치합니다. 이걸 빼면 막대가 겹쳐요.
    • 정렬 안 하면 읽기 어려움! 순서 없는 막대 차트는 비교가 힘듭니다. 항상 기준 항목으로 정렬하세요.

    ✅ 점검하기¶

    1. 그룹 막대 차트에서 막대가 겹치지 않게 하려면 어떤 값을 조절해야 할까요?

    정답 확인각 막대의 x(또는 y) 위치를 width(또는 height)만큼 빼거나 더해서 나란히 배치합니다. 예: x - width/2, x + width/2

    2. 선수 이름이 "Christopher Alexander"처럼 길다면 세로와 가로 중 어떤 막대 차트가 적합할까요?

    정답 확인가로 막대 차트(barh)가 적합합니다. 긴 텍스트 라벨이 y축에 자연스럽게 표시되어 겹치지 않습니다.

    3. np.argsort(goals)는 무엇을 반환하나요?

    정답 확인goals를 오름차순으로 정렬했을 때의 원래 인덱스 순서를 반환합니다. 이를 이용해 다른 리스트도 같은 순서로 정렬할 수 있습니다.
