    숫자일까, 글자일까? — 데이터 타입 구분하기¶

    🎯 이 장에서 배우는 것¶

    • 구글 시트에서 숫자, 문자, 날짜 데이터 타입을 구분할 수 있다
    • 데이터 타입에 따라 할 수 있는 작업이 달라짐을 이해할 수 있다
    • 셀의 정렬 방향과 서식 메뉴로 데이터 타입을 판별할 수 있다

    📚 핵심 개념¶

    개념: 데이터 타입¶

    1. 비유로 시작 🎒 "데이터 타입은 마치 분리수거 표시와 같아요." 플라스틱은 플라스틱끼리, 종이는 종이끼리 모아야 재활용할 수 있죠? 데이터도 마찬가지입니다. 숫자는 숫자끼리 계산할 수 있고, 문자는 문자끼리 이어 붙일 수 있어요. 종류가 섞이면 엉뚱한 결과가 나옵니다!

    2. 정확한 정의 구글 시트에서 다루는 대표적인 데이터 타입 세 가지입니다.

    3. 숫자 — 계산이 가능한 값 (예: 85, 92.5)

    4. 문자(텍스트) — 글자로 취급되는 값 (예: 김민수, A반)

    5. 날짜 — 시간 정보를 담은 값 (예: 2025-03-15)

    6. 예시로 확인 👀 성적표를 떠올려 보세요. "김민수"는 문자, 점수 "85"는 숫자, 시험일 "2025-03-15"는 날짜입니다. 이름끼리 평균을 구할 수 없고, 점수끼리는 평균을 구할 수 있죠 — 이것이 바로 타입이 다르기 때문입니다.

    💡 시각적 단서: 구글 시트에서 아무 서식도 지정하지 않으면, 숫자와 날짜는 오른쪽 정렬, 문자는 왼쪽 정렬됩니다. 정렬 방향만 봐도 타입을 짐작할 수 있어요!

    🔨 따라하기¶

    Step 1: 성적 데이터 입력하기¶

    구글 시트를 열고 아래처럼 입력해 보세요.

    • A1: 이름 → A2: 김민수 → A3: 이영희
    • B1: 점수 → B2: 85 → B3: 92
    • C1: 시험일 → C2: 2025-03-15 → C3: 2025-03-15

    입력 후 정렬 방향을 관찰하세요. 김민수는 왼쪽, 85와 2025-03-15는 오른쪽에 붙어 있나요? 그렇다면 시트가 타입을 제대로 인식한 것입니다! 🎉

    Step 2: 타입이 다르면 결과도 다르다¶

    B4 셀에 평균 수식을 입력합니다.

    =AVERAGE(B2:B3)

    실행 결과: 

    88.5

    숫자니까 평균이 잘 구해집니다. 이제 A4 셀에 같은 수식을 입력해 보세요.

    =AVERAGE(A2:A3)

    실행 결과: 

    #DIV/0!

    에러가 나죠? 😅 문자는 계산 대상이 아니기 때문입니다. 데이터 타입이 작업 가능 범위를 결정한다는 것을 직접 확인했습니다!

    ⚠️ 주의할 점¶

    • 숫자처럼 보여도 문자일 수 있어요! 셀에 '85처럼 앞에 작은따옴표(')를 붙이면 구글 시트는 이것을 문자로 인식합니다. 왼쪽 정렬이 되면 의심해 보세요.
    • 셀 서식 확인법: 셀을 선택한 뒤 메뉴에서 서식 → 숫자를 확인하면 현재 타입(자동, 일반 텍스트, 숫자, 날짜 등)을 직접 볼 수 있습니다.

    ✅ 점검하기¶

    1. 구글 시트에서 아무 서식 없이 데이터를 입력했을 때, 문자는 어느 쪽으로 정렬되나요?
    정답 확인왼쪽으로 정렬됩니다. 반대로 숫자와 날짜는 오른쪽으로 정렬됩니다.
    1. 학생 이름이 들어 있는 셀 범위에 =AVERAGE()를 적용하면 어떻게 되나요?
    정답 확인에러(#DIV/0!)가 발생합니다. 문자는 숫자 계산 함수의 대상이 아니기 때문입니다.
    1. 셀에 입력한 85가 문자로 인식되고 있는지 확인하는 방법 두 가지는?
    정답 확인① 정렬 방향 확인 — 왼쪽 정렬이면 문자일 가능성이 높습니다. ② **서식 → 숫자** 메뉴에서 "일반 텍스트"로 표시되는지 확인합니다.
