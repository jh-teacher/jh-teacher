    나만의 데이터 이야기 만들기 — 종합 시각화 프로젝트¶

    🎯 이 장에서 배우는 것¶

    • 스포츠 데이터에서 주제를 정하고 적합한 차트를 선택할 수 있다
    • 2개 이상의 차트를 조합하여 하나의 데이터 스토리를 완성할 수 있다
    • 제목, 설명, 출처를 갖춘 완성도 있는 시각화 결과물을 만들 수 있다

    📚 핵심 개념¶

    개념: 데이터 스토리텔링¶

    1. 비유로 시작: 데이터 스토리텔링은 마치 사진 한 장이 아니라 포토 에세이를 만드는 것과 같아요. 사진 한 장은 순간을 보여주지만, 여러 장을 엮으면 이야기가 됩니다. 차트도 마찬가지예요!

    2. 정확한 정의: 데이터 스토리텔링이란 여러 시각화를 논리적 흐름으로 배치하여, 데이터가 말하는 이야기를 보는 사람에게 전달하는 것입니다.

    3. 예시로 확인: "우리 팀 공격력 분석"이라는 주제라면 이런 흐름이 됩니다.

    flowchart LR A["🏟️ 전체 현황\n득점 순위 막대 차트"] --> B["🔍 구성 분석\n포지션별 원형 차트"] B --> C["💡 인사이트 발견\n출전-득점 산점도"]

    전체 → 부분 → 인사이트 순서로 이야기를 풀어가는 거예요. 이 흐름만 기억하면 어떤 주제든 스토리를 만들 수 있습니다! 🎯

    🔨 따라하기¶

    Step 1: 데이터 준비 & 차트 3개 한 번에 구성하기¶

    "축구팀 공격력 분석"이라는 주제로 미니 프로젝트를 완성해 봅시다.

    코드:

    import matplotlib.pyplot as plt

# 한글 폰트 설정 (환경에 맞게 수정)
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

# 📊 선수 데이터
names = ['손흥민', '김민재', '이강인', '황희찬', '정우영']
goals = [8, 1, 5, 6, 3]
appearances = [20, 22, 18, 15, 12]
positions = {'FW': 3, 'MF': 1, 'DF': 1}

# 🎨 3개 차트를 하나의 화면에 배치
fig, axes = plt.subplots(1, 3, figsize=(15, 5))

# 전체 제목 — 이것이 "이야기의 제목"
fig.suptitle('⚽ 우리 팀 공격력 분석 리포트', fontsize=16, fontweight='bold')

# 차트 1: 득점 순위 (전체 현황)
colors = ['gold' if g == max(goals) else 'skyblue' for g in goals]
axes[0].barh(names, goals, color=colors)
axes[0].set_title('① 선수별 득점 순위')
axes[0].set_xlabel('득점 수')

# 차트 2: 포지션 구성 (부분 분석)
axes[1].pie(positions.values(), labels=positions.keys(),
            autopct='%1.0f%%', colors=['#ff9999','#66b3ff','#99ff99'])
axes[1].set_title('② 득점자 포지션 구성')

# 차트 3: 출전-득점 관계 (인사이트)
axes[2].scatter(appearances, goals, s=100, c='coral', edgecolors='black')
for i, name in enumerate(names):
    axes[2].annotate(name, (appearances[i]+0.3, goals[i]))
axes[2].set_title('③ 출전 횟수 vs 득점')
axes[2].set_xlabel('출전 횟수')
axes[2].set_ylabel('득점 수')

# 출처 표시 — 완성도의 핵심!
fig.text(0.5, -0.02, '출처: 2024 시즌 팀 기록 (예시 데이터)',
         ha='center', fontsize=9, color='gray')

plt.tight_layout()
plt.savefig('my_data_story.png', bbox_inches='tight', dpi=150)
plt.show()

    실행 결과: 

    3개의 차트가 나란히 배치된 하나의 리포트가 출력됩니다.
- 왼쪽: 손흥민이 금색으로 강조된 가로 막대 차트
- 가운데: FW 60%, MF 20%, DF 20% 원형 차트
- 오른쪽: 출전 많을수록 득점 많은 경향이 보이는 산점도
- 하단에 출처 텍스트 표시

    Step 2: 나만의 주제로 바꿔보기¶

    위 코드에서 데이터와 제목만 바꾸면 나만의 프로젝트가 됩니다! 주제 아이디어 💡

    • "농구팀 득점 패턴" → 쿼터별 점수 + 선수별 슛 성공률 + 리바운드-득점 관계
    • "야구 타자 분석" → 타율 순위 + 좌타/우타 비율 + 안타-출루 관계

    📝 전체 코드¶

    import matplotlib.pyplot as plt

plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

names = ['손흥민', '김민재', '이강인', '황희찬', '정우영']
goals = [8, 1, 5, 6, 3]
appearances = [20, 22, 18, 15, 12]
positions = {'FW': 3, 'MF': 1, 'DF': 1}

fig, axes = plt.subplots(1, 3, figsize=(15, 5))
fig.suptitle('⚽ 우리 팀 공격력 분석 리포트', fontsize=16, fontweight='bold')

colors = ['gold' if g == max(goals) else 'skyblue' for g in goals]
axes[0].barh(names, goals, color=colors)
axes[0].set_title('① 선수별 득점 순위')
axes[0].set_xlabel('득점 수')

axes[1].pie(positions.values(), labels=positions.keys(),
            autopct='%1.0f%%', colors=['#ff9999','#66b3ff','#99ff99'])
axes[1].set_title('② 득점자 포지션 구성')

axes[2].scatter(appearances, goals, s=100, c='coral', edgecolors='black')
for i, name in enumerate(names):
    axes[2].annotate(name, (appearances[i]+0.3, goals[i]))
axes[2].set_title('③ 출전 횟수 vs 득점')
axes[2].set_xlabel('출전 횟수')
axes[2].set_ylabel('득점 수')

fig.text(0.5, -0.02, '출처: 2024 시즌 팀 기록 (예시 데이터)',
         ha='center', fontsize=9, color='gray')

plt.tight_layout()
plt.savefig('my_data_story.png', bbox_inches='tight', dpi=150)
plt.show()

    ⚠️ 주의할 점¶

    • 차트 순서가 곧 스토리 흐름입니다. "전체 현황 → 세부 분석 → 인사이트" 순서를 지키면 보는 사람이 자연스럽게 따라갑니다.
    • fig.suptitle과 fig.text를 잊지 마세요. 전체 제목과 출처가 없으면 "누가 만든 무슨 차트인지" 알 수 없어요. 이 두 줄이 완성도를 결정합니다! ✨

    ✅ 점검하기¶

    1. 데이터 스토리텔링에서 차트 배치의 권장 흐름은?

    정답 확인전체 현황 → 부분/세부 분석 → 인사이트 발견 순서로 배치합니다.

    2. 시각화 결과물의 완성도를 높이기 위해 반드시 포함해야 할 3가지는?

    정답 확인① 전체 제목(suptitle) ② 각 차트의 개별 제목(set_title) ③ 데이터 출처(fig.text)입니다.

    3. plt.subplots(1, 3)에서 1과 3은 각각 무엇을 의미하나요?

    정답 확인1은 행(row) 수, 3은 열(column) 수입니다. 즉, 1행 3열로 차트 3개를 가로로 나란히 배치합니다.
