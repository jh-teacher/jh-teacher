    전체 마무리 — 3차시 여정 돌아보기와 다음 단계 안내¶

    🎯 이 장에서 배우는 것¶

    • 3차시 전체에서 반복된 5단계 흐름을 자신의 말로 설명할 수 있다
    • 구글 시트 → 파이썬/코랩으로 이어지는 다음 단계를 이해할 수 있다
    • 데이터를 다루는 기본 감각에 자신감을 가질 수 있다

    📚 핵심 개념¶

    개념: 데이터 분석의 5단계 흐름¶

    1. 비유로 시작: "5단계 흐름은 마치 요리 레시피와 같아요. 재료 확인 → 상태 점검 → 손질 → 조리 → 플레이팅. 어떤 요리든 이 순서는 같죠. 데이터도 마찬가지입니다!" 🍳

    2. 정확한 정의: 어떤 데이터를 만나든 반복하는 기본 과정

    3. ① 구조 파악 — 행과 열, 무엇이 담겨 있나?

    4. ② 타입 확인 — 숫자인지, 텍스트인지 구분
    5. ③ 결측·이상값 점검 — 빈 칸, 이상한 값 찾기
    6. ④ 정렬·필터 — 원하는 조건으로 데이터 좁히기

    7. ⑤ 시각화 — 차트로 패턴 발견하기

    8. 3차시 여정에서 확인

    flowchart LR A["🎒 Part1\n성적 데이터"] --> B["🌦️ Part2\n날씨 데이터"] B --> C["⚽ Part3\n스포츠 데이터"] style A fill:#FFE0B2 style B fill:#B3E5FC style C fill:#C8E6C9

    데이터 주제는 달라졌지만, 매번 같은 5단계를 반복했다는 걸 눈치채셨나요? 이것이 바로 데이터 분석의 핵심 루틴입니다! 💡

    🔨 따라하기¶

    Step 1: 내가 걸어온 길 체크하기¶

    아래 항목을 스스로 점검해 보세요. ✔️가 4개 이상이면 훌륭합니다!

    • ✔️ 구글 시트에서 데이터 구조(행·열)를 파악할 수 있다
    • ✔️ 숫자와 텍스트 타입을 구분할 수 있다
    • ✔️ 빈 칸(결측값)을 찾고 처리하는 방법을 안다
    • ✔️ 정렬과 필터로 원하는 데이터를 골라낼 수 있다
    • ✔️ 차트를 만들어 데이터의 패턴을 설명할 수 있다

    Step 2: 다음 단계 미리 맛보기¶

    구글 시트에서 손으로 했던 작업, 파이썬으로는 이렇게 짧아집니다:

    # 판다스로 5단계를 한번에! (미리보기)
import pandas as pd

df = pd.read_csv("sports.csv")   # ① 구조 파악
print(df.dtypes)                  # ② 타입 확인
print(df.isnull().sum())          # ③ 결측값 점검
top5 = df.sort_values("득점", ascending=False).head(5)  # ④ 정렬
top5.plot(kind="bar", x="선수", y="득점")               # ⑤ 시각화

    구글 시트에서 원리를 이해했기 때문에, 코드가 낯설지 않을 거예요! 🚀

    ⚠️ 주의할 점¶

    • 도구가 달라져도 흐름은 같습니다 — 엑셀이든, 파이썬이든, 5단계는 변하지 않아요
    • 완벽하지 않아도 괜찮아요 — 데이터를 직접 만지고 차트를 그려본 경험 자체가 가장 큰 자산입니다 🌱

    ✅ 점검하기¶

    1. 데이터 분석 5단계를 순서대로 말해보세요.
    정답 확인구조 파악 → 타입 확인 → 결측·이상값 점검 → 정렬·필터 → 시각화
    1. 3차시 동안 다룬 데이터 주제 3가지는?
    정답 확인성적 데이터, 날씨 데이터, 스포츠 데이터
    1. 구글 시트 경험이 파이썬 학습에 도움이 되는 이유는?
    정답 확인원리(5단계 흐름)를 이미 이해했기 때문에, 코드는 그 원리를 실행하는 도구일 뿐이라 쉽게 연결됩니다.
