    결측값 심화 탐색 — 빈칸이 생기는 진짜 이유¶

    🎯 이 장에서 배우는 것¶

    • 날씨 데이터에서 다양한 형태의 결측값(빈 셀, 'N/A', '-' 등)을 식별할 수 있다
    • 결측값의 발생 원인을 데이터 맥락에서 추론할 수 있다
    • COUNTBLANK와 조건 함수를 조합하여 결측값을 체계적으로 탐색할 수 있다

    📚 핵심 개념¶

    개념: 결측값의 다양한 얼굴¶

    비유로 시작 🕵️

    결측값은 마치 여러 가지 변장을 한 빈자리와 같아요. 어떤 빈자리는 아예 텅 비어 있고, 어떤 빈자리는 "해당 없음"이라는 쪽지가 붙어 있고, 또 어떤 빈자리는 "-"라는 줄표만 덩그러니 놓여 있죠. 겉모습은 다르지만, 본질은 같습니다 — 실제 값이 없다는 뜻이에요.

    정확한 정의

    결측값(Missing Value)은 수집되었어야 할 데이터가 존재하지 않는 상태입니다. 스프레드시트에서는 다음과 같은 형태로 나타납니다.

    • 빈 셀 → 아무것도 입력되지 않음
    • 'N/A' → "Not Available"의 약자로 기록자가 직접 입력
    • '-' 또는 '측정불가' → 장비 고장 등의 이유로 기록 불가

    예시로 확인 — 왜 빈칸이 생길까? 🌦️

    기상 관측소의 날씨 데이터를 떠올려 보세요.

    • 장비 고장: 풍속 센서가 얼어서 측정 불가 → '-' 기록
    • 기록 누락: 관측원이 야간에 습도를 빠뜨림 → 빈 셀
    • 해당 없음: 비가 오지 않은 날의 강수량 → 'N/A' 입력

    이처럼 같은 "값 없음"이라도 이유가 다릅니다. 이유를 아는 것이 올바른 처리의 첫걸음이에요.

    🔨 따라하기¶

    Step 1: 날씨 데이터 만들고 결측값 현황 파악하기¶

    import pandas as pd

# 가상의 날씨 관측 데이터 생성
data = {
    '날짜': ['2024-01-01', '2024-01-02', '2024-01-03',
            '2024-01-04', '2024-01-05', '2024-01-06'],
    '기온(℃)': [2.1, -3.5, None, 1.0, 'N/A', -1.2],
    '습도(%)': [45, None, 60, '-', 55, None],
    '풍속(m/s)': [3.2, 2.8, '측정불가', None, 4.1, '-']
}
df = pd.DataFrame(data)
print("📋 원본 데이터:")
print(df)

    📋 원본 데이터:

3  2024-01-04    1.0      -     None

    None은 눈에 보이지만, 'N/A', '-', '측정불가'는 문자열로 숨어 있는 결측값입니다! 😮

    Step 2: 모든 형태의 결측값을 통합 탐색하기¶

    # 1단계: 변장한 결측값을 진짜 결측값(NaN)으로 통일
df_clean = df.replace(['N/A', '-', '측정불가'], pd.NA)

# 2단계: 열별 결측값 개수와 비율 확인
missing_count = df_clean.isna().sum()
missing_ratio = (df_clean.isna().sum() / len(df_clean) * 100).round(1)

print("🔍 열별 결측값 개수:")
print(missing_count)
print("\n📊 열별 결측값 비율(%):")
print(missing_ratio)

    습도와 풍속은 절반이 결측이네요! 이런 열은 분석 시 각별한 주의가 필요합니다. ⚠️

    📝 전체 코드¶

    import pandas as pd

# 가상의 날씨 관측 데이터
data = {
    '날짜': ['2024-01-01', '2024-01-02', '2024-01-03',
            '2024-01-04', '2024-01-05', '2024-01-06'],
    '기온(℃)': [2.1, -3.5, None, 1.0, 'N/A', -1.2],
    '습도(%)': [45, None, 60, '-', 55, None],
    '풍속(m/s)': [3.2, 2.8, '측정불가', None, 4.1, '-']
}
df = pd.DataFrame(data)
print("📋 원본 데이터:")
print(df)

# 변장한 결측값을 NaN으로 통일
df_clean = df.replace(['N/A', '-', '측정불가'], pd.NA)

# 열별 결측값 개수와 비율
missing_count = df_clean.isna().sum()
missing_ratio = (df_clean.isna().sum() / len(df_clean) * 100).round(1)

print("\n🔍 열별 결측값 개수:")
print(missing_count)
print("\n📊 열별 결측값 비율(%):")
print(missing_ratio)

    ⚠️ 주의할 점¶

    1. isna()만으로는 부족합니다! 'N/A'나 '-'는 pandas가 문자열로 인식하므로, 반드시 replace()로 먼저 변환한 뒤 탐색해야 합니다.
    2. 결측값 비율이 너무 높은 열(예: 70% 이상)은 분석에 포함할지 신중히 판단하세요. 빈 값이 절반 이상이면 평균·합계 등의 결과가 왜곡될 수 있습니다.

    ✅ 점검하기¶

    1. 결측값이 빈 셀 외에 어떤 형태로 숨어 있을 수 있나요?

    정답 확인 'N/A', '-', '측정불가', '없음' 등 사람이 직접 입력한 문자열 형태로 숨어 있을 수 있습니다. 이런 값은 pandas가 자동으로 결측으로 인식하지 못합니다.

    2. replace()를 먼저 실행하지 않고 isna().sum()만 하면 어떤 문제가 생길까요?

    정답 확인 'N/A', '-' 같은 문자열은 결측이 아닌 정상 값으로 집계됩니다. 결과적으로 결측값 개수가 실제보다 적게 나와, 데이터 품질을 과대평가하게 됩니다.

    3. 습도 열의 결측값 비율 50%는 분석에 어떤 영향을 줄 수 있을까요?

    정답 확인 6개 중 3개만으로 평균을 구하면 전체를 대표하기 어렵습니다. 특정 날짜(예: 야간)에만 누락되었다면 편향된 결과가 나올 수 있어, 결측 원인 파악이 중요합니다.
