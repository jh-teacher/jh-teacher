    이상한 점수를 찾아라! — 이상값 이해와 탐색¶

    🎯 이 장에서 배우는 것¶

    • 이상값이 무엇인지 설명하고, 평균을 얼마나 왜곡하는지 체감할 수 있다
    • MIN, MAX 함수와 조건부 서식으로 이상값을 찾아낼 수 있다

    📚 핵심 개념¶

    개념: 이상값(Outlier)¶

    1. 비유로 시작 🎯

    교실에서 키를 측정하는데, 한 명이 실수로 "1700cm"라고 기록했다고 상상해보세요. 평균을 내면? 우리 반 평균 키가 갑자기 2m를 넘어버립니다! 이상값은 마치 조용한 합창단에 끼어든 확성기와 같아요 — 하나가 전체를 압도해버리죠.

    2. 정확한 정의

    이상값(Outlier): 다른 데이터들과 동떨어져 있는 극단적인 값. 입력 실수, 측정 오류, 또는 실제로 특이한 경우에 발생합니다.

    3. 예시로 확인

    수학 점수 데이터에 이런 값이 있다면?

    • -5점 → ❌ 점수는 음수가 될 수 없음 (입력 실수)
    • 350점 → ❌ 100점 만점인데 범위 초과 (입력 실수)
    • 23점 → ✅ 낮지만 가능한 점수 (이상값 아님)

    핵심은 "있을 수 없는 값"과 "낮거나 높을 뿐인 값"을 구분하는 것입니다. 이번 장에서는 0~100 범위를 벗어나는 명백한 이상값을 찾는 데 집중합니다.

    🔨 따라하기¶

    Step 1: MIN, MAX로 수상한 값 찾기¶

    우리의 성적 데이터에서 수학 점수가 B2:B11에 있다고 가정합니다.

    구글 시트에 입력하세요:

    B2:B11에 다음 값을 입력
85, 92, 78, -5, 88, 95, 350, 72, 90, 68

    빈 셀에 아래 수식을 입력합니다:

    =MIN(B2:B11)    → 결과: -5
=MAX(B2:B11)    → 결과: 350

    결과 해석: 최솟값이 -5, 최댓값이 350! 😱 둘 다 0~100 범위를 벗어나므로 이상값입니다.

    Step 2: 조건부 서식으로 이상값 빨갛게 표시하기¶

    눈으로 하나하나 찾는 건 비효율적이에요. 자동으로 색칠해봅시다!

    1. B2:B11 범위를 드래그하여 선택
    2. 메뉴 → 서식 → 조건부 서식
    3. "맞춤 수식" 선택 후 입력: =OR(B2<0, B2>100)
    4. 서식 스타일 → 배경색을 빨간색으로 설정
    5. 완료 클릭

    ✨ -5와 350 셀이 빨갛게 변합니다! 이제 데이터가 수백 개여도 이상값이 한눈에 보이죠.

    🔍 이상값이 평균에 미치는 영향을 직접 확인해보세요:

    =AVERAGE(B2:B11)  → 이상값 포함 평균: 91.3 (왜곡됨!)

    -5와 350을 정상 값(예: 65, 80)으로 수정한 후 다시 평균을 보면, 현실적인 평균(81.3)이 나옵니다. 이상값 2개가 평균을 10점이나 끌어올린 셈이에요!

    ⚠️ 주의할 점¶

    • 낮은 점수 ≠ 이상값: 30점은 낮지만 가능한 점수입니다. 섣불리 삭제하면 안 돼요!
    • 이상값은 바로 삭제하지 마세요: 원본 데이터는 보존하고, 왜 이 값이 생겼는지 먼저 확인하는 습관이 중요합니다.

    ✅ 점검하기¶

    1. 다음 중 이상값은 어느 것일까요? (수학 점수, 0~100점 기준) 88, 45, -10, 73, 102, 91

    정답 확인 **-10**과 **102**가 이상값입니다. 0 미만이거나 100을 초과하는 값은 점수 범위를 벗어나기 때문이에요.

    2. 이상값이 포함된 채로 평균을 구하면 어떤 문제가 생기나요?

    정답 확인 극단적으로 크거나 작은 값이 평균을 끌어올리거나 끌어내려서, **실제 학생들의 성적 수준을 왜곡**합니다.

    3. 조건부 서식에서 =OR(B2<0, B2>100) 수식의 의미는?

    정답 확인 "B2 값이 0보다 작거나(OR) 100보다 크면" 조건이 참이 됩니다. 즉, **정상 범위(0~100)를 벗어나는 셀**에 서식을 적용하라는 뜻이에요.
