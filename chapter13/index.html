    정렬과 필터로 날씨 데이터 탐험하기¶

    🎯 이 장에서 배우는 것¶

    • 날씨 데이터를 기온·강수량 기준으로 정렬할 수 있다
    • 필터로 특정 조건의 데이터만 추출할 수 있다
    • 복합 조건 필터로 원하는 답을 찾을 수 있다

    📚 핵심 개념¶

    개념: 정렬과 필터¶

    1. 비유로 시작: 정렬은 카드를 크기순으로 늘어놓는 것, 필터는 원하는 색 카드만 골라내는 것과 같아요 🃏

    2. 정확한 정의

    3. 정렬(sort_values): 특정 열 기준으로 데이터를 오름차순/내림차순 배치

    4. 필터(조건 인덱싱): 조건에 맞는 행만 추출

    5. 예시로 확인: "가장 더운 날은?" → 기온 내림차순 정렬, "비 온 날만 보기" → 날씨 == '비' 필터

    🔨 따라하기¶

    Step 1: 데이터 준비 & 정렬¶

    import pandas as pd

# 날씨 데이터 생성
weather = pd.DataFrame({
    '날짜': ['6/1','6/2','6/3','6/4','6/5','6/6','6/7'],
    '최고기온': [28, 32, 35, 27, 30, 33, 26],
    '강수량': [0, 0, 0, 15, 5, 0, 20],
    '날씨': ['맑음','맑음','맑음','비','비','맑음','비']
})

# 최고기온 내림차순 정렬 → 가장 더운 날 찾기!
hot_rank = weather.sort_values('최고기온', ascending=False)
print(hot_rank.head(3))

    실행 결과: 

      날짜  최고기온  강수량   날씨
2  6/3    35     0  맑음
5  6/6    33     0  맑음
1  6/2    32     0  맑음

    🔥 6월 3일이 35도로 가장 더웠네요!

    Step 2: 필터 & 복합 필터¶

    # 비 온 날만 필터링
rainy = weather[weather['날씨'] == '비']
print("비 온 날 평균 강수량:", rainy['강수량'].mean())

# 복합 조건: 기온 30도 이상이면서 강수량 0인 날
hot_dry = weather[(weather['최고기온'] >= 30) & (weather['강수량'] == 0)]
print("\n무더운 맑은 날:")
print(hot_dry)

    실행 결과: 

    비 온 날 평균 강수량: 13.333333333333334

무더운 맑은 날:
  날짜  최고기온  강수량   날씨
1  6/2    32     0  맑음
2  6/3    35     0  맑음
5  6/6    33     0  맑음

    📝 전체 코드¶

    import pandas as pd

weather = pd.DataFrame({
    '날짜': ['6/1','6/2','6/3','6/4','6/5','6/6','6/7'],
    '최고기온': [28, 32, 35, 27, 30, 33, 26],
    '강수량': [0, 0, 0, 15, 5, 0, 20],
    '날씨': ['맑음','맑음','맑음','비','비','맑음','비']
})

# 정렬: 가장 더운 날 TOP 3
print(weather.sort_values('최고기온', ascending=False).head(3))

# 필터: 비 온 날 평균 강수량
rainy = weather[weather['날씨'] == '비']
print("비 온 날 평균 강수량:", rainy['강수량'].mean())

# 복합 필터: 30도 이상 + 강수량 0
hot_dry = weather[(weather['최고기온'] >= 30) & (weather['강수량'] == 0)]
print(hot_dry)

    ⚠️ 주의할 점¶

    • 복합 조건은 각 조건을 ()로 감싸세요! &(그리고), |(또는) 앞뒤 조건 모두 괄호 필수
    • ascending=False는 내림차순(큰 값부터), 기본값 True는 오름차순

    ✅ 점검하기¶

    1. 강수량이 가장 많은 날을 찾으려면 어떤 코드를 쓸까요?
    정답 확인weather.sort_values('강수량', ascending=False).head(1)
    1. 복합 조건에서 & 대신 |를 쓰면 결과가 어떻게 달라질까요?
    정답 확인&는 두 조건을 모두 만족하는 행만, |는 둘 중 하나라도 만족하면 포함되어 결과가 더 많아집니다.
