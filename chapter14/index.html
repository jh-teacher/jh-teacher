    날씨 데이터 시각화 — 꺾은선 차트와 비교 차트¶

    🎯 이 장에서 배우는 것¶

    • 시간 흐름에 따른 기온 변화를 꺾은선 차트로 표현할 수 있다
    • 최고기온과 최저기온을 하나의 차트에 함께 그려 비교할 수 있다
    • 막대 차트와 꺾은선 차트의 적합한 상황을 구분할 수 있다

    📚 핵심 개념¶

    개념: 꺾은선 차트 (Line Chart)¶

    비유로 시작 🎢

    꺾은선 차트는 마치 롤러코스터의 궤적과 같아요. 시간이 흐르면서 기온이 올라갔다 내려갔다 하는 흐름과 추세를 한눈에 보여줍니다.

    정확한 정의

    꺾은선 차트는 연속적인 데이터 포인트를 선으로 연결하여 변화의 흐름을 보여주는 차트입니다. X축에 시간, Y축에 측정값을 놓는 것이 일반적입니다.

    막대 vs 꺾은선, 언제 쓸까?

    flowchart LR Q{"데이터 성격은?"} Q -->|"항목별 크기 비교<br>(도시별 강수량)"| B["📊 막대 차트"] Q -->|"시간에 따른 변화<br>(일별 기온 추이)"| L["📈 꺾은선 차트"]

    💡 기억법: "비교하려면 막대, 흐름을 보려면 꺾은선!"

    🔨 따라하기¶

    Step 1: 일별 최고기온 꺾은선 차트 그리기¶

    import matplotlib.pyplot as plt

# 7일간 날씨 데이터
days = ["월", "화", "수", "목", "금", "토", "일"]
high_temp = [22, 25, 23, 28, 30, 27, 24]  # 최고기온

plt.figure(figsize=(8, 4))
plt.plot(days, high_temp, marker="o", color="tomato", label="최고기온")
plt.title("일주일 최고기온 변화")
plt.xlabel("요일")
plt.ylabel("기온(°C)")
plt.legend()
plt.grid(True)
plt.show()

    실행 결과: 요일별 기온이 선으로 연결되어 목~금에 기온이 치솟는 추세가 한눈에 보입니다. marker="o"가 각 데이터 포인트를 동그라미로 찍어줍니다. 🔴

    Step 2: 최고기온 + 최저기온 비교 차트¶

    plt.plot()을 두 번 호출하면 하나의 차트에 선 두 개가 그려집니다!

    import matplotlib.pyplot as plt

days = ["월", "화", "수", "목", "금", "토", "일"]
high_temp = [22, 25, 23, 28, 30, 27, 24]
low_temp  = [14, 16, 15, 18, 20, 17, 15]  # 최저기온

plt.figure(figsize=(8, 4))
plt.plot(days, high_temp, marker="o", color="tomato", label="최고기온")
plt.plot(days, low_temp, marker="s", color="steelblue", label="최저기온")
plt.title("일주일 기온 변화 (최고 vs 최저)")
plt.xlabel("요일")
plt.ylabel("기온(°C)")
plt.legend()
plt.grid(True)
plt.show()

    실행 결과: 빨간 선(최고)과 파란 선(최저) 사이의 간격이 일교차입니다. 금요일에 두 선의 간격이 10°C로 가장 크네요! 🌡️

    📝 전체 코드¶

    import matplotlib.pyplot as plt

days = ["월", "화", "수", "목", "금", "토", "일"]
high_temp = [22, 25, 23, 28, 30, 27, 24]
low_temp  = [14, 16, 15, 18, 20, 17, 15]

plt.figure(figsize=(8, 4))
plt.plot(days, high_temp, marker="o", color="tomato", label="최고기온")
plt.plot(days, low_temp, marker="s", color="steelblue", label="최저기온")
plt.title("일주일 기온 변화 (최고 vs 최저)")
plt.xlabel("요일")
plt.ylabel("기온(°C)")
plt.legend()
plt.grid(True)
plt.show()

    ⚠️ 주의할 점¶

    • label을 빠뜨리면 범례가 비어요! plt.plot()에 label을 쓰고, 반드시 plt.legend()를 호출해야 범례가 나타납니다.
    • 선이 두 개 이상일 때는 색상을 확실히 구분하세요. 비슷한 색을 쓰면 어떤 선이 뭔지 알 수 없습니다.

    ✅ 점검하기¶

    1. 꺾은선 차트가 막대 차트보다 적합한 상황은?

    정답 확인시간의 흐름에 따른 변화(추세)를 보여줄 때 꺾은선 차트가 적합합니다. 예: 일별 기온 변화, 월별 판매 추이 등

    2. 하나의 차트에 선을 두 개 그리려면 어떻게 하나요?

    정답 확인plt.plot()을 두 번 호출하면 됩니다. 각각 다른 데이터, 색상, label을 지정하고 plt.legend()로 범례를 표시합니다.

    3. 비교 차트에서 두 선 사이의 간격은 무엇을 의미하나요?

    정답 확인최고기온 선과 최저기온 선 사이의 간격은 그날의 일교차를 나타냅니다. 간격이 클수록 일교차가 큰 날입니다.
