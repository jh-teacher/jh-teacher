    날씨 데이터와 만나기 — 구조와 타입 빠르게 파악하기¶

    🎯 이 장에서 배우는 것¶

    • 날씨 데이터의 행·열·셀 구조를 빠르게 파악할 수 있다
    • 숫자·문자·날짜 등 다양한 데이터 타입을 구분할 수 있다
    • 이전에 배운 탐색 방법을 새로운 데이터에 적용할 수 있다

    📚 핵심 개념¶

    개념: 데이터 타입이 섞인 표 읽기¶

    1. 비유로 시작: 성적 데이터가 "같은 과목의 시험지 묶음"이었다면, 날씨 데이터는 "매일 쓰는 날씨 일기장"과 같아요. 날짜, 숫자(기온), 글자(맑음/흐림) 등 종류가 다른 정보가 한 줄에 모여 있죠! 📓

    2. 정확한 정의: 하나의 데이터프레임 안에 날짜형·숫자형·문자형 열이 공존하는 것을 혼합 타입 데이터라고 합니다. dtypes로 각 열의 타입을 확인하는 것이 탐색의 첫걸음입니다.

    3. 예시로 확인: 날짜(2024-01-01)는 문자처럼 보이지만 날짜형, 최고기온(5.2)은 숫자형, 날씨 상태(맑음)는 문자형 — 겉모습만으로 판단하면 안 돼요!

    🔨 따라하기¶

    Step 1: 날씨 데이터 만들고 구조 확인하기¶

    import pandas as pd

# 날씨 데이터 생성
weather = pd.DataFrame({
    "날짜": pd.to_datetime(["2024-01-01", "2024-01-02", "2024-01-03", "2024-01-04", "2024-01-05"]),
    "최고기온": [5.2, 3.8, -1.0, 2.5, 7.1],
    "최저기온": [-2.1, -3.5, -8.2, -4.0, 0.3],
    "강수량": [0.0, 12.5, 0.0, 3.2, 0.0],
    "날씨상태": ["맑음", "비", "맑음", "흐림", "맑음"]
})

print(weather.head())     # 앞부분 확인
print(weather.shape)      # 행·열 개수
print(weather.dtypes)     # 열별 타입 확인

    실행 결과:

    🔍 포인트: datetime64 = 날짜형, float64 = 소수점 숫자형, object = 문자형. 한 표에 세 가지 타입이 섞여 있어요!

    Step 2: 성적 데이터와 비교해 보기¶

    # 성적 데이터 (이전 차시 복습)
scores = pd.DataFrame({
    "이름": ["민수", "지영"], "국어": [85, 92], "수학": [90, 88]
})

print("날씨 타입:", list(weather.dtypes.unique()))
print("성적 타입:", list(scores.dtypes.unique()))

    실행 결과: 

    날씨 타입: [dtype('<M8[ns]'), dtype('float64'), dtype('O')]
성적 타입: [dtype('O'), dtype('int64')]

    💡 깨달음: 구조(행·열·셀)는 같지만, 담긴 데이터 타입의 다양성이 다릅니다. 날씨 데이터가 더 복잡해요!

    📝 전체 코드¶

    import pandas as pd

weather = pd.DataFrame({
    "날짜": pd.to_datetime(["2024-01-01", "2024-01-02", "2024-01-03", "2024-01-04", "2024-01-05"]),
    "최고기온": [5.2, 3.8, -1.0, 2.5, 7.1],
    "최저기온": [-2.1, -3.5, -8.2, -4.0, 0.3],
    "강수량": [0.0, 12.5, 0.0, 3.2, 0.0],
    "날씨상태": ["맑음", "비", "맑음", "흐림", "맑음"]
})

print(weather.head())
print(weather.shape)
print(weather.dtypes)

    ⚠️ 주의할 점¶

    • 날짜를 문자열로 방치하지 마세요! pd.to_datetime()을 쓰지 않으면 날짜가 그냥 문자(object)로 저장되어 시간순 정렬·계산이 안 됩니다.
    • dtypes 확인은 습관! 숫자처럼 보여도 문자로 저장된 경우가 실무에서 매우 흔합니다.

    ✅ 점검하기¶

    1. weather.shape가 (5, 5)일 때, 행과 열은 각각 몇 개인가요?
    정답 확인행 5개(5일치 데이터), 열 5개(날짜·최고기온·최저기온·강수량·날씨상태)
    1. 날씨상태 열의 타입이 object인 이유는?
    정답 확인"맑음", "비" 등 문자열 데이터이기 때문입니다. pandas에서 문자열은 object 타입으로 표시됩니다.
    1. pd.to_datetime()을 쓰지 않으면 어떤 문제가 생길까요?
    정답 확인날짜가 단순 문자열로 저장되어 날짜 기준 정렬, 기간 계산 등 시간 관련 연산을 할 수 없습니다.
