    성적 데이터 들여다보기 — 행, 열, 셀 완전 정복¶

    🎯 이 장에서 배우는 것¶

    • 셀 주소(예: B3)의 의미를 이해하고, 원하는 데이터를 찾을 수 있다
    • 데이터의 크기를 "몇 행 × 몇 열"로 표현할 수 있다
    • 행은 한 학생(관측값), 열은 과목(변수)이라는 개념을 설명할 수 있다

    📚 핵심 개념¶

    개념: 행, 열, 셀¶

    1. 비유로 시작: 스프레드시트는 마치 아파트 주소 체계와 같아요. 열(A, B, C…)은 동, 행(1, 2, 3…)은 호수입니다. "B3"이라고 하면 B동 3호 — 딱 하나의 방(셀)을 가리키죠! 🏠

    2. 정확한 정의

    3. 행(Row): 가로 한 줄. 한 학생의 모든 정보 → 데이터 분석에서는 관측값이라 부릅니다
    4. 열(Column): 세로 한 줄. 이름, 국어, 영어 같은 항목 → 변수라 부릅니다

    5. 셀(Cell): 행과 열이 만나는 한 칸. 열 알파벳 + 행 번호로 주소를 읽습니다

    6. 예시로 확인: 30명의 성적 데이터가 있다면, 1행은 헤더(제목)이고 2~31행이 학생 데이터이므로 31행 × 5열 크기입니다. "C4"는 3번째 학생의 국어 점수가 들어있는 셀이에요.

    🔨 따라하기¶

    Step 1: 성적 데이터 만들고 살펴보기¶

    구글 시트에서 아래 코드를 실행하면 연습용 성적 데이터가 만들어집니다.

    코드: 

    import pandas as pd
import random

# 30명 성적 데이터 생성
random.seed(42)
data = {
    "이름": [f"학생{i}" for i in range(1, 31)],
    "국어": [random.randint(50, 100) for _ in range(30)],
    "영어": [random.randint(50, 100) for _ in range(30)],
    "수학": [random.randint(50, 100) for _ in range(30)],
}
df = pd.DataFrame(data)

# 데이터 크기 확인
print(f"데이터 크기: {df.shape[0]}행 × {df.shape[1]}열")
print()
print(df.head())  # 처음 5명만 미리보기

    실행 결과: 

    데이터 크기: 30행 × 4열

    이름  국어  영어  수학
0  학생1   81   53   89
1  학생2   64   84   68
2  학생3   70   71   97
3  학생4   55   93   56
4  학생5   68   59   72

    Step 2: 특정 셀 찾기 미션! 🎯¶

    "3번째 학생의 수학 점수"를 찾아봅시다.

    코드: 

    # 3번째 학생(인덱스 2)의 수학 점수 찾기
value = df.loc[2, "수학"]
print(f"3번째 학생({df.loc[2, '이름']})의 수학 점수: {value}점")

    실행 결과: 

    3번째 학생(학생3)의 수학 점수: 97점

    💡 스프레드시트에서는 "D4" 셀에 해당합니다 (D열=수학, 4행=학생3).

    📝 전체 코드¶

    import pandas as pd
import random

random.seed(42)
data = {
    "이름": [f"학생{i}" for i in range(1, 31)],
    "국어": [random.randint(50, 100) for _ in range(30)],
    "영어": [random.randint(50, 100) for _ in range(30)],
    "수학": [random.randint(50, 100) for _ in range(30)],
}
df = pd.DataFrame(data)

print(f"데이터 크기: {df.shape[0]}행 × {df.shape[1]}열")
print()
print(df.head())
print()
print(f"3번째 학생({df.loc[2, '이름']})의 수학 점수: {df.loc[2, '수학']}점")

    ⚠️ 주의할 점¶

    • 인덱스는 0부터 시작해요! 3번째 학생은 df.loc[2]입니다. 스프레드시트 행 번호와 1씩 차이가 나니 헷갈리지 마세요.
    • 데이터를 받으면 shape부터 확인하는 습관을 들이세요. "몇 행 몇 열인지"를 먼저 파악하는 것이 데이터 분석의 진짜 첫걸음입니다! 🏃

    ✅ 점검하기¶

    1. df.shape의 결과가 (30, 4)일 때, 이 데이터는 몇 행 몇 열인가요?
    정답 확인30행 × 4열입니다. 30개의 관측값(학생)과 4개의 변수(이름, 국어, 영어, 수학)가 있습니다.
    1. 스프레드시트에서 "C2" 셀은 무엇을 의미하나요? (1행이 헤더일 때)
    정답 확인C열(영어)의 2행, 즉 1번째 학생의 영어 점수입니다.
    1. "행 = 관측값, 열 = 변수"에서 성적 데이터의 관측값과 변수는 각각 무엇인가요?
    정답 확인관측값은 각 학생(한 행에 한 학생의 모든 정보), 변수는 이름·국어·영어·수학(각 열의 항목)입니다.
